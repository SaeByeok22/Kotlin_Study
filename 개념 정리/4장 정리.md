## 1. 인터페이스

Kotlin의 인터페이스는 추상 메서드뿐 아니라 기본 구현도 가질 수 있다.

```kotlin
interface Clickable {
    fun click()

    fun showMessage() {
        println("클릭되었습니다.")
    }
}
```

인터페이스 구현:

```kotlin
class Button : Clickable {
    override fun click() {
        println("버튼 클릭")
    }
}
```

- 인터페이스 구현 시 `: 인터페이스명`
- 메서드 재정의 시 `override`
- 여러 인터페이스를 구현할 수 있다.

---

## 2. 상속

Kotlin의 클래스와 메서드는 기본적으로 `final`이다.

상속을 허용하려면 `open`을 사용해야 한다.

```kotlin
open class Animal {
    open fun makeSound() {
        println("소리")
    }
}

class Dog : Animal() {
    override fun makeSound() {
        println("멍멍")
    }
}
```

### 주요 키워드

| 키워드 | 의미 |
|---|---|
| `open` | 상속 또는 재정의 허용 |
| `final` | 상속 또는 재정의 금지 |
| `abstract` | 추상 클래스나 추상 멤버 |
| `override` | 부모 클래스나 인터페이스 멤버 재정의 |

> Kotlin은 실수로 상속하거나 재정의하는 것을 막기 위해 기본값이 `final`이다.

## 3. 접근 제한자

| 접근 제한자 | 의미 |
|---|---|
| `public` | 어디서나 접근 가능. 기본값 |
| `internal` | 같은 모듈 내부에서 접근 가능 |
| `protected` | 클래스와 하위 클래스에서 접근 가능 |
| `private` | 선언된 클래스나 파일 내부에서만 접근 가능 |

```kotlin
class User {
    private val password = "secret"

    fun checkPassword() {
        println(password)
    }
}
```

## 4. 중첩 클래스와 내부 클래스

Kotlin의 중첩 클래스는 기본적으로 바깥 클래스의 인스턴스를 참조하지 않는다.

```kotlin
class Outer {
    class Nested {
        fun test() {
            println("중첩 클래스")
        }
    }
}
```

사용:

```kotlin
val nested = Outer.Nested()
```

바깥 클래스의 인스턴스를 참조하려면 `inner`를 사용한다.

```kotlin
class Outer {
    private val text = "Outer"

    inner class Inner {
        fun printText() {
            println(text)
        }
    }
}
```

- `nested class`: 바깥 클래스 참조 없음
- `inner class`: 바깥 클래스 참조 가능

## 5. sealed class

제한된 클래스 계층을 표현할 때 사용한다.

```kotlin
sealed class Result {
    class Success(val data: String) : Result()
    class Error(val message: String) : Result()
}
```

`when`과 함께 사용하면 모든 하위 타입을 검사할 수 있다.

```kotlin
fun handle(result: Result): String {
    return when (result) {
        is Result.Success -> result.data
        is Result.Error -> result.message
    }
}
```

활용 예시:

- 성공과 실패 상태
- 화면 상태
- 네트워크 결과
- 이벤트 종류
- 제한된 명령 타입

## 6. 주 생성자와 초기화 블록

### 주 생성자

```kotlin
class Person(
    val name: String,
    var age: Int
)
```

### init 블록

객체가 생성될 때 실행할 초기화 코드를 작성한다.

```kotlin
class Person(val name: String) {
    init {
        println("$name 객체 생성")
    }
}
```

### 생성자 매개변수 검증

```kotlin
class User(val age: Int) {
    init {
        require(age >= 0) {
            "나이는 음수가 될 수 없습니다."
        }
    }
}
```

## 7. 부 생성자

주 생성자 외에 추가 생성자를 정의할 수 있다.

```kotlin
class Person(val name: String) {
    var age: Int = 0

    constructor(name: String, age: Int) : this(name) {
        this.age = age
    }
}
```

다른 클래스를 상속하는 경우 부모 생성자를 호출해야 한다.

```kotlin
open class Parent(val value: Int)

class Child(value: Int) : Parent(value)
```

## 8. 인터페이스 프로퍼티 구현

인터페이스에 프로퍼티를 선언할 수 있다.

```kotlin
interface User {
    val nickname: String
}

class PrivateUser(
    override val nickname: String
) : User
```

getter를 직접 구현할 수도 있다.

```kotlin
class UserImpl : User {
    override val nickname: String
        get() = "Kotlin"
}
```

## 9. backing field와 field

프로퍼티의 getter나 setter에서 실제 저장 공간에 접근하려면 `field`를 사용한다.

```kotlin
class User {
    var name: String = ""
        set(value) {
            field = value.trim()
        }
}
```

- `field`: 프로퍼티의 실제 저장 공간
- getter/setter 내부에서만 사용 가능
- 프로퍼티 이름을 직접 사용하면 재귀 호출이 발생할 수 있다.

## 10. 접근자 visibility 변경

getter와 setter의 접근 제한자를 다르게 설정할 수 있다.

```kotlin
class User {
    var name: String = ""
        private set
}
```

외부에서는 값을 읽을 수 있지만 변경할 수 없다.

```kotlin
val user = User()
println(user.name)
// user.name = "철수" // 외부에서 변경 불가
```

## 11. Any, equals, hashCode, toString

모든 Kotlin 클래스의 최상위 타입은 `Any`이다.

대표적인 메서드:

- `toString()`: 객체를 문자열로 표현
- `equals()`: 객체의 동등성 비교
- `hashCode()`: 해시값 반환

```kotlin
class Person(val name: String) {
    override fun toString(): String {
        return "Person(name=$name)"
    }
}
```

## 12. 데이터 클래스

데이터를 저장하는 목적의 클래스는 `data class`로 선언한다.

```kotlin
data class User(
    val name: String,
    val age: Int
)
```

컴파일러가 다음 기능을 자동으로 생성한다.

- `toString()`
- `equals()`
- `hashCode()`
- `copy()`
- `componentN()`

```kotlin
val user = User("철수", 20)
val updatedUser = user.copy(age = 21)

println(user)
println(updatedUser)
```

### 구조 분해

```kotlin
val (name, age) = user

println(name)
println(age)
```

## 13. 클래스 위임

`by` 키워드를 사용해 다른 객체에 구현을 위임할 수 있다.

```kotlin
interface Printer {
    fun print()
}

class ConsolePrinter : Printer {
    override fun print() {
        println("출력")
    }
}

class PrinterWrapper(
    private val printer: Printer
) : Printer by printer
```

클래스 위임의 장점:

- 상속보다 구성을 선호할 수 있다.
- 반복적인 위임 코드를 줄인다.
- 기능을 다른 객체에 맡길 수 있다.

## 14. object 선언

클래스 선언과 인스턴스 생성을 동시에 수행한다.

```kotlin
object DatabaseManager {
    fun connect() {
        println("데이터베이스 연결")
    }
}

DatabaseManager.connect()
```

`object` 선언은 싱글턴 객체를 만들 때 사용한다.

활용 예시:

- 전역 설정 객체
- 로그 관리자
- 데이터베이스 관리자
- 무상태 유틸리티 객체

## 15. companion object

클래스 내부에서 정적 멤버와 비슷한 기능을 제공한다.

```kotlin
class User private constructor(val name: String) {
    companion object {
        fun create(name: String): User {
            return User(name)
        }
    }
}

val user = User.create("철수")
```

Java의 `static`과 비슷하게 사용할 수 있지만, 실제로는 companion object라는 객체의 멤버다.

## 16. object 표현식

이름 없는 객체를 즉시 생성할 수 있다.

```kotlin
val listener = object {
    fun onClick() {
        println("클릭")
    }
}

listener.onClick()
```

인터페이스 구현이나 일회성 객체 생성에도 사용할 수 있다.

```kotlin
val comparator = object : Comparator<String> {
    override fun compare(a: String, b: String): Int {
        return a.length - b.length
    }
}
```

## 17. value class

값 하나를 별도의 타입으로 감싸 타입 안정성을 높일 수 있다.

```kotlin
@JvmInline
value class UserId(val value: String)

fun findUser(id: UserId) {
    println(id.value)
}
```

장점:

- 서로 다른 의미의 문자열이나 숫자를 구분할 수 있다.
- 잘못된 인자 전달을 줄일 수 있다.
- 컴파일러 최적화에 따라 추가 객체 생성을 줄일 수 있다.
