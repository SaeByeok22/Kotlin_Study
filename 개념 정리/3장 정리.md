## 1. 컬렉션

Kotlin은 Java 컬렉션을 사용할 수 있으며, 컬렉션을 생성하는 함수도 제공한다.

```kotlin
val list = listOf("A", "B", "C")
val mutableList = mutableListOf("A", "B")
val set = setOf(1, 2, 3)
val map = mapOf("a" to 1, "b" to 2)
```

### 읽기 전용 컬렉션과 변경 가능한 컬렉션

```kotlin
val readOnly = listOf(1, 2, 3)

val mutable = mutableListOf(1, 2, 3)
mutable.add(4)
```

- `listOf`: 읽기 전용 리스트
- `mutableListOf`: 수정 가능한 리스트
- `setOf`: 중복을 허용하지 않는 집합
- `mapOf`: 키와 값의 쌍

## 2. 이름 있는 인자

함수 호출 시 인자 이름을 명시할 수 있다.

```kotlin
fun createUser(name: String, age: Int) {
    println("$name, $age")
}

createUser(name = "철수", age = 20)
```

장점:

- 인자의 의미가 명확해진다.
- 인자 순서를 헷갈리지 않는다.
- Boolean 인자가 많은 함수에서 유용하다.

---

## 3. 기본 인자

함수 매개변수에 기본값을 지정할 수 있다.

```kotlin
fun greet(name: String, message: String = "안녕하세요") {
    println("$message, $name")
}

greet("철수")
greet("영희", "반갑습니다")
```

Java에서 오버로딩으로 처리하던 상황을 기본 인자로 간단하게 표현할 수 있다.

## 4. 최상위 함수와 프로퍼티

Kotlin에서는 클래스 밖 파일의 최상위에 함수와 프로퍼티를 선언할 수 있다.

```kotlin
const val APP_NAME = "Kotlin Study"

fun printAppName() {
    println(APP_NAME)
}
```

Java의 유틸리티 클래스를 만들지 않고도 공통 함수를 작성할 수 있다.

---

## 5. 확장 함수

기존 클래스를 수정하지 않고 새로운 함수를 추가할 수 있다.

```kotlin
fun String.lastChar(): Char = this[this.length - 1]

val result = "Kotlin".lastChar()
println(result)
```

- `String`: 수신 객체 타입
- `lastChar`: 확장 함수 이름
- `this`: 확장 대상 객체

### 확장 함수의 특징

- 기존 클래스를 실제로 수정하지 않는다.
- 상속 없이 기능을 추가할 수 있다.
- 확장 함수는 정적으로 결정된다.
- 멤버 함수와 이름이 같으면 멤버 함수가 우선된다.
- 확장 함수는 재정의할 수 없다.

## 6. 확장 프로퍼티

확장 함수처럼 프로퍼티도 추가할 수 있다.

```kotlin
val String.lastChar: Char
    get() = this[length - 1]

println("Kotlin".lastChar)
```

확장 프로퍼티는 실제로 값을 저장할 수 없으며 getter나 setter를 통해 계산된다.

## 7. 가변 인자 - vararg

인자의 개수를 정하지 않고 여러 값을 받을 수 있다.

```kotlin
fun printAll(vararg values: String) {
    for (value in values) {
        println(value)
    }
}

printAll("A", "B", "C")
```

배열을 전달할 때는 spread 연산자 `*`를 사용한다.

```kotlin
val names = arrayOf("철수", "영희")

printAll(*names)
```

## 8. 중위 호출

매개변수가 하나인 함수는 `infix` 키워드를 사용해 중위 호출 형태로 작성할 수 있다.

```kotlin
infix fun Int.plusValue(value: Int): Int {
    return this + value
}

val result = 10 plusValue 20
```

Kotlin의 `to`도 중위 호출의 예이다.

```kotlin
val pair = "name" to "Kotlin"
```

## 9. Pair와 구조 분해 선언

### Pair

두 값을 하나로 묶을 수 있다.

```kotlin
val pair = Pair("Kotlin", 2024)

println(pair.first)
println(pair.second)
```

또는 `to`를 사용할 수 있다.

```kotlin
val pair = "Kotlin" to 2024
```

### 구조 분해 선언

객체의 여러 값을 각각의 변수로 나눌 수 있다.

```kotlin
val (language, year) = "Kotlin" to 2024

println(language)
println(year)
```

Map 순회에서도 사용할 수 있다.

```kotlin
val scores = mapOf("철수" to 90, "영희" to 85)

for ((name, score) in scores) {
    println("$name: $score")
}
```

## 10. 문자열 다루기

### 문자열 분리

```kotlin
val text = "A,B,C"
val values = text.split(",")

println(values)
```

### 정규 표현식

```kotlin
val regex = """\d+""".toRegex()

println(regex.matches("123")) // true
println(regex.matches("abc")) // false
```

### 삼중 따옴표 문자열

이스케이프 없이 여러 줄 문자열을 작성할 수 있다.

```kotlin
val text = """
    첫 번째 줄
    두 번째 줄
    세 번째 줄
""".trimIndent()
```

- `"""`를 사용한다.
- 여러 줄 문자열에 유용하다.
- 정규 표현식 작성 시에도 편리하다.
- `trimIndent()`로 공통 들여쓰기를 제거할 수 있다.

## 11. 지역 함수

함수 내부에 또 다른 함수를 선언할 수 있다.

```kotlin
fun printUser(name: String, age: Int) {
    fun validate(value: String) {
        require(value.isNotBlank())
    }

    validate(name)
    println("$name, $age")
}
```

지역 함수는 특정 함수 안에서만 사용하는 로직을 숨길 때 유용하다.
