- Kotlin 함수와 변수 선언 방법 이해

## 1. 함수와 변수

### 함수 선언

Kotlin에서는 `fun` 키워드로 함수를 선언한다.

```kotlin
fun greet(name: String): String {
    return "Hello, $name"
}
```

- `fun`: 함수라고 선언하는 키워드
- `greet`: 함수 이름
- `name: String`: 매개변수: 타입
- `: String`: 반환 타입
- `return`: 결과 반환

### 표현식 본문

함수 본문이 한 줄이면 중괄호와 `return`을 생략할 수 있다.

```kotlin
fun greet(name: String): String = "Hello, $name"
```

반환 타입도 추론할 수 있기 때문에 생략할 수 있다.

```kotlin
fun greet(name: String) = "Hello, $name"
```

### 변수 선언

```kotlin
val name = "Kotlin"
var age = 10
```

| 키워드 | 의미 |
|---|---|
| `val` | 읽기 전용 변수. 선언 후 재할당 불가 |
| `var` | 변경 가능한 변수. 재할당 가능 |

```kotlin
val language = "Kotlin"
// language = "Java" // 오류

var count = 1
count = 2 // 가능
```

> `val`은 참조 자체를 바꿀 수 없다는 뜻이다.  
> 객체 내부의 값이 항상 변경 불가능하다는 의미는 아니다.

### 타입 추론

Kotlin은 변수에 저장된 값으로 타입을 추론한다.

```kotlin
val number = 10       // Int
val message = "Hello" // String
val active = true     // Boolean
```

필요하면 타입을 직접 지정할 수 있다.

```kotlin
val number: Int = 10
val message: String = "Hello"
```

### 문자열 템플릿

문자열 안에 변수나 표현식을 넣을 수 있다.

```kotlin
val name = "Kotlin"
println("Hello, $name")
```

표현식은 `${}`를 사용한다.

```kotlin
val a = 10
val b = 20

println("합계: ${a + b}")
```

## 2. 클래스와 프로퍼티

### 클래스 선언

```kotlin
class Person(val name: String, var age: Int)
```

생성자 매개변수 앞에 `val` 또는 `var`를 붙이면 프로퍼티가 된다.

```kotlin
val person = Person("홍길동", 20)

println(person.name)
person.age = 21
```

### 프로퍼티

Kotlin의 프로퍼티는 값을 저장하거나 계산할 수 있다.

```kotlin
class Rectangle(
    val width: Int,
    val height: Int
) {
    val area: Int
        get() = width * height
}
```

- `val`: getter만 사용
- `var`: getter와 setter 사용 가능
- `get()`: 값을 가져올 때 실행되는 코드

### 커스텀 getter

```kotlin
class Person(val name: String) {
    val greeting: String
        get() = "안녕하세요, $name"
}
```

### 패키지와 import

파일의 첫 줄에 패키지를 선언할 수 있다.

```kotlin
package com.example.study
```

다른 패키지의 함수를 사용하려면 `import`를 사용한다.

```kotlin
import com.example.study.greet
```

Kotlin에서는 클래스 내부뿐 아니라 파일 최상위에도 함수와 변수를 선언할 수 있다.

```kotlin
fun main() {
    println("프로그램 시작")
}
```

## 3. 조건 처리와 when

### if 표현식

Kotlin의 `if`는 값을 반환할 수 있다.

```kotlin
val max = if (a > b) a else b
```

여러 줄로 작성할 수도 있다.

```kotlin
val result = if (number > 0) {
    "양수"
} else {
    "0 또는 음수"
}
```

### enum class

정해진 종류의 값을 표현할 때 사용한다.

```kotlin
enum class Color {
    RED, GREEN, BLUE
}
```

프로퍼티가 있는 enum도 만들 수 있다.

```kotlin
enum class Color(val code: String) {
    RED("#FF0000"),
    GREEN("#00FF00"),
    BLUE("#0000FF")
}
```

### when 표현식

여러 조건을 처리할 때 사용한다.

```kotlin
val color = Color.RED

val result = when (color) {
    Color.RED -> "빨간색"
    Color.GREEN -> "초록색"
    Color.BLUE -> "파란색"
}
```

`else`를 사용할 수도 있다.

```kotlin
val result = when (number) {
    1 -> "하나"
    2 -> "둘"
    else -> "기타"
}
```

### 여러 조건을 하나로 묶기

```kotlin
val result = when (number) {
    1, 2, 3 -> "작은 수"
    4, 5, 6 -> "큰 수"
    else -> "범위 밖"
}
```

### 인자가 없는 when

```kotlin
val result = when {
    number > 0 -> "양수"
    number < 0 -> "음수"
    else -> "0"
}
```

### 타입 검사와 스마트 캐스트

`is`로 타입을 확인할 수 있다.

```kotlin
fun describe(value: Any): String {
    return when (value) {
        is String -> "문자열 길이: ${value.length}"
        is Int -> "정수: $value"
        else -> "알 수 없는 타입"
    }
}
```

타입 검사가 끝나면 Kotlin이 자동으로 해당 타입으로 변환해준다.  
이것을 스마트 캐스트라고 한다.

## 4. 반복문과 범위

### while

```kotlin
var count = 0

while (count < 3) {
    println(count)
    count++
}
```

### do-while

조건을 나중에 검사하므로 본문이 최소 한 번 실행된다.

```kotlin
var count = 0

do {
    println(count)
    count++
} while (count < 3)
```

### for

```kotlin
for (i in 1..5) {
    println(i)
}
```

### 범위 표현식

```kotlin
1..5       // 1부터 5까지
1 until 5  // 1부터 4까지
5 downTo 1 // 5부터 1까지
1..10 step 2 // 2씩 증가
```

예시:

```kotlin
for (i in 1..10 step 2) {
    println(i)
}
```

### 컬렉션 순회

```kotlin
val names = listOf("철수", "영희", "민수")

for (name in names) {
    println(name)
}
```

### Map 순회

```kotlin
val scores = mapOf(
    "철수" to 90,
    "영희" to 85
)

for ((name, score) in scores) {
    println("$name: $score")
}
```

### in과 !in

값이 범위나 컬렉션에 포함되는지 검사한다.

```kotlin
val number = 3

println(number in 1..5)    // true
println(number !in 1..5)   // false
```

## 5. 예외 처리

### 예외 발생시키기

```kotlin
throw IllegalArgumentException("잘못된 인자입니다.")
```

### try-catch

```kotlin
try {
    val number = "abc".toInt()
} catch (e: NumberFormatException) {
    println("숫자로 변환할 수 없습니다.")
}
```

### finally

예외 발생 여부와 관계없이 실행할 코드를 작성한다.

```kotlin
try {
    println("작업 시작")
} catch (e: Exception) {
    println("예외 발생")
} finally {
    println("작업 종료")
}
```

### try 표현식

Kotlin에서 `try`는 값을 반환하는 표현식으로 사용할 수 있다.

```kotlin
val number = try {
    "123".toInt()
} catch (e: NumberFormatException) {
    0
}

println(number)
```

### Kotlin의 예외 특징

- `try-catch-finally`를 사용한다.
- 예외는 객체로 표현된다.
- Java의 checked exception을 강제하지 않는다.
- `try` 자체가 값을 반환할 수 있다.
