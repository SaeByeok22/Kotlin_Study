## 학습 목표

- 람다 표현식이 무엇인지 이해
- 람다를 변수·함수 인자로 사용하는 방법 익히기
- 멤버 참조 사용하기
- Java의 함수형 인터페이스와 SAM 변환 이해
- `with`, `apply`, `also` 사용하기

---

## 1. 람다 표현식

람다(lambda)는 이름 없이 만든 함수다.

```kotlin
val sum = { a: Int, b: Int ->
    a + b
}

println(sum(10, 20)) // 30
```

형태:

```kotlin
{ 매개변수 -> 실행할 코드 또는 반환값 }
```

---

## 2. 함수 타입

Kotlin에서는 함수를 변수에 담을 수 있다.

```kotlin
val multiply: (Int, Int) -> Int = { a, b ->
    a * b
}

println(multiply(3, 4)) // 12
```

함수 타입 문법:

```kotlin
(매개변수 타입) -> 반환 타입
```

예시:

```kotlin
(Int) -> Int
(String) -> Boolean
() -> Unit
(String, Int) -> String
```

`Unit`은 Java의 `void`와 비슷하게 반환값이 없다는 의미다.

```kotlin
val printMessage: (String) -> Unit = { message ->
    println(message)
}
```

---

## 3. `it`

람다의 매개변수가 하나면 이름을 생략하고 `it`으로 사용할 수 있다.

```kotlin
val numbers = listOf(1, 2, 3, 4)

val evenNumbers = numbers.filter {
    it % 2 == 0
}

println(evenNumbers) // [2, 4]
```

아래 두 코드는 같은 의미다.

```kotlin
numbers.filter { number -> number > 2 }

numbers.filter { it > 2 }
```

---

## 4. 컬렉션과 람다

### `filter`

조건에 맞는 값만 남긴다.

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

val evenNumbers = numbers.filter {
    it % 2 == 0
}

println(evenNumbers) // [2, 4]
```

### `map`

각 값을 변환한다.

```kotlin
val numbers = listOf(1, 2, 3)

val doubled = numbers.map {
    it * 2
}

println(doubled) // [2, 4, 6]
```

---

## 5. 람다의 반환값

람다에서는 마지막 표현식이 자동으로 반환된다.

```kotlin
val square = { number: Int ->
    number * number
}

println(square(5)) // 25
```

`return`은 보통 사용하지 않는다.

```kotlin
val square = { number: Int ->
    return number * number // 오류
}
```

## 6. 바깥 변수 사용 - 캡처

람다는 자신이 선언된 바깥쪽 변수를 사용할 수 있다.

```kotlin
fun main() {
    var count = 0

    val increase = {
        count++
    }

    increase()
    increase()

    println(count) // 2
}
```

람다가 바깥 변수를 기억하고 사용하는 것을 **변수 캡처**라고 한다.

## 7. 멤버 참조

람다 대신 기존 함수나 프로퍼티를 가리킬 수 있다.

```kotlin
fun greet() {
    println("Hello")
}

fun main() {
    val action = ::greet

    action()
}
```

`::`는 함수나 프로퍼티를 참조할 때 사용한다.

### 프로퍼티 참조

```kotlin
data class Person(val name: String)

fun main() {
    val people = listOf(
        Person("철수"),
        Person("영희")
    )

    val names = people.map(Person::name)

    println(names) // [철수, 영희]
}
```

다음과 같은 의미다.

```kotlin
val names = people.map {
    it.name
}
```

## 8. Java 함수형 인터페이스와 SAM 변환

Java의 `Runnable`처럼 추상 메서드가 하나뿐인 인터페이스를 함수형 인터페이스라고 한다.

```java
public interface Runnable {
    void run();
}
```

Kotlin에서는 Java 함수형 인터페이스가 필요한 자리에 람다를 바로 전달할 수 있다.

```kotlin
fun main() {
    val thread = Thread {
        println("새 스레드에서 실행")
    }

    thread.start()
}
```

위 코드는 사실상 다음과 비슷하다.

```kotlin
val thread = Thread(
    object : Runnable {
        override fun run() {
            println("새 스레드에서 실행")
        }
    }
)
```

## 9. `fun interface`

Kotlin에서도 함수형 인터페이스를 직접 만들 수 있다.

```kotlin
fun interface ClickListener {
    fun onClick()
}
```

람다를 전달할 수 있다.

```kotlin
fun register(listener: ClickListener) {
    listener.onClick()
}

fun main() {
    register {
        println("클릭됨")
    }
}
```

조건:

- 추상 메서드가 하나여야 한다.
- `fun interface` 키워드를 사용한다.

## 10. 수신 객체가 있는 람다

특정 객체를 람다 내부에서 바로 사용할 수 있는 형태다.

```kotlin
val getLength: String.() -> Int = {
    length
}

fun main() {
    println("Kotlin".getLength()) // 6
}
```

`String.() -> Int`는 String 객체를 대상으로 실행되는 람다라는 뜻이다.

---

## 11. `with`

한 객체를 여러 번 사용할 때 편리하다.

```kotlin
fun main() {
    val result = with(StringBuilder()) {
        append("Hello")
        append(" ")
        append("Kotlin")

        toString()
    }

    println(result)
}
```

- 람다 내부에서 객체를 `this`처럼 사용
- 마지막 표현식이 반환값
- 주로 객체를 이용해 결과를 만들 때 사용

---

## 12. `apply`

객체를 만들고 초기화할 때 사용한다.

```kotlin
fun main() {
    val builder = StringBuilder().apply {
        append("Hello")
        append(" Kotlin")
    }

    println(builder)
}
```

- 람다 내부에서 객체를 `this`처럼 사용
- 반환값은 객체 자신
- 객체 설정·초기화에 적합

---

## 13. `also`

객체를 그대로 반환하면서 부가 작업을 할 때 사용한다.

```kotlin
fun main() {
    val numbers = mutableListOf(1, 2, 3)
        .also {
            println("생성된 리스트: $it")
        }

    println(numbers)
}
```

- 람다 내부에서 객체를 `it`으로 사용
- 반환값은 객체 자신
- 로그 출력, 디버깅에 유용

---

## `with`, `apply`, `also` 비교

| 함수 | 람다 안에서 객체 이름 | 반환값 | 주 사용 목적 |
|---|---|---|---|
| `with` | `this` | 람다의 마지막 결과 | 객체를 사용해 값 만들기 |
| `apply` | `this` | 객체 자신 | 객체 초기화 |
| `also` | `it` | 객체 자신 | 로그 등 부가 작업 |
